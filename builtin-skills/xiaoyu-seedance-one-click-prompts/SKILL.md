# 一键成片提示词-seedance适配版

<!-- 源自 horizontal-tv-shotlist-v2，agent/stage3-scene-canvas @ b23592f。 -->

给剧本和场地即可开始。默认一次交付 Stage 3 画布。Stage 2 是内部编写步骤，完成本场的来源与适用范围核对后即默认通过，继续写镜头。无需另交固定卡、等待回复或索取 Stage 1 批准文件。用户主动要求先看某一阶段时，按当次范围交付。本技能交付提示词；提交生成、剪辑和发布按用户另行指定的任务执行。

## 从输入取得镜头依据

画幅以用户指定或项目已定的横竖方向、宽高比为准。按实际画幅核对人物裁切、多人站位、关键道具和运动终点是否入画。画幅未定时，保留两种画幅都能表达的必要空间关系。

剧本决定谁做什么、何时揭示信息、谁说哪句原话。场地照片、平面图或场地文字决定能据实使用的空间、布景和光源。区分现场已有条件与本次选择的拍法；参考名只是画布挂载位置，只有实际提供的素材才能作为已绑定参考。

- **有分镜**：沿用镜号、镜序、时长、摄影机、动作、对白、音效和剪辑决定。七列分镜中的摄影机、画面内容和音效原文依次组成「分镜内容」。剪辑衔接决定动作或声音如何接入下一镜。
- **仅有剧本和场地**：按剧情场序在内部形成必要的镜头依据。从观众先看到什么、谁接收到变化、在什么动作或反应处切出，确定机位、主体、可见范围和时长。直接填入成品的「分镜内容」。不要求用户先做分镜，也不另交七列表。跨镜保留朝向、视线、持物、进出画和声音接续；留够说完原话和接反应的时间。

## Stage 2 · 自动形成每场全局提示词

按[固定条件的取舍](references/stable-conditions.md)选择本场反复使用、容易漂移的条件。优先采用用户给定的风格和设定。场地条件不足以决定的细节，能用合理拍法解决就自行选择；只有相互冲突的硬条件会改变剧情或使镜头无法落地时，指出具体冲突，继续其他可完成的场次。

1. 光影沿「光源位置、人物受光、暗部细节、背景层次」写。不同人物或群体在不同灯区时，分别写其可见结果。自然光可定性，技术布光可沿用项目给定的 K / lux 或注明设计目标。
2. 环境写材质、受力对象、动静与幅度。群演按身份分组，每条外观参考写明人种／族裔、年龄范围、性别范围、发色、发型、身高、身材和服装差异。大型人群写各项的取值范围，限定人群写共同条件及组内造型差异，写到范围为止。仅当同组群演整场反应相近时写动作参考；反应随剧情变化时，把各次反应写进对应分镜。全局省略背景描述。同期声按需补入，音色仅在用户启用时写。
3. 对照剧本和场地检查每项的对象、区域、时段。用户已指定的条件优先。自查完成即采用该版本，在同一轮将完整正文置入本场 Stage 3 的全局格。无需用户回复“通过”。省去人工确认仍应写足光影与适用的环境、群演等正文；每场视觉风格只写一句简短的风格定位。优先用用户原话，未指定时按剧本和场景提炼。

## Stage 3 · 生成逐场画布

按[场次画布规范](references/scene-canvas.md)写作；[可复制的双镜示例](references/canvas-example.md)展示空格、时码和段落格式。每场或续段先放一格全局正文，再写五列「镜号｜片段｜时长｜分镜内容｜Seedance提示词」。仅有具体问题时加备注。全场条件写在全局格，逐镜落实它在当前构图和时刻可见、可闻的结果。例如窗外的人群从近景裁出后，不再让他们出现在画面里。

每镜以片段内时码和摄影机开头，再依次写「画面」「动作/表情」「情感解析」「声音」。画面只写第一帧。动作/表情写谁先行动、对方如何接收、说哪句原话、摄影机从哪里动到哪里。对白保留原语言、说话人和顺序，只出现一次。声音写对应的同期声，无其他声音写「声音：N/A」。单镜内容独立可读；全局光影默认只在场级出现。

换场或返回前场时开新段，每段从 0 秒累计，片段号在交付范围内连续递增。每段至多 30 秒，按完整镜头边界分组；真实入口有更短上限时按指定入口安排。已有分镜的单镜超出时长时，指出具体镜号，不擅自截短对白。已有分镜保留原时长精度；新编时长从台词、动作和反应反推。参考主体过多时优先在完整镜头之间分段。

默认交付同源的 Markdown 主稿和逐场 Excel，若用户指定纯文本或单个片段则按需给出。Markdown 用示例中的表格和换行格式。导出 Excel 时运行 `node scripts/export-canvas.mjs 主稿.md 画布.xlsx`（在本技能目录执行；使用含 `@oai/artifact-tool` 的 Node 环境，Codex 桌面可用工作区依赖的 Node，并把其包目录设为 `NODE_PATH`）。导出时会核对各场全局格、逐镜行及 Excel 回读。交付前再对照剧本检查原话、动作归属与场次连续性。

用户要单独粘贴某段时，输出「所属场次完整全局正文＋本段镜头正文＋无配乐无字幕」。修改某场全局设定后，同步该场受影响的镜头、续段及已导出的片段正文。
