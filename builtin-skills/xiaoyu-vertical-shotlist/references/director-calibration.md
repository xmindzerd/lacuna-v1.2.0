# 导演偏好校准

用户提供参考视频、分镜样本或简短偏好说明时，使用本参考。

## 使用边界

本文件提供样本经验，编号、台词语言、原文一致性、镜头时长、摄影机字段和输入范围按 `../SKILL.md` 执行。先依据整集节奏确定重点，再选适合当前剧情的样本经验。

- 市场包括国内外竖屏短剧，样本的英语人物与台词不决定当前剧本的语言或市场。
- 单集戏或多场戏片段以单集为单位编排，场号为集数-场次，镜号如 `13-1A`；跨集连续戏分别编号。
- 分镜采用 `镜号`、`摄影机`、`分镜内容` 三列。摄影机按主体、焦段、机位、角度、高度、运镜、构图书写；分镜内容以时长开头。
- 台词逐字采用剧本已有且选定的语言版本。大段台词跨镜连续承载，并明确听者反应及画外续接。
- 样本中的镜头密度与情绪停留需适配当前严格时长规则。参考视频总长属于样本信息，不能直接作为本次镜头时长。

## 个人镜头偏好

- 单人对白可用过肩、斜侧单人净镜头，或带高平低角度及机位高度的构图。过肩和斜侧镜头都可采用俯拍、平视、仰拍。
- 同段对话内，同一人物的同角度、同景别累计第 4 次起，考虑更换构图；中间切过其他人物也计数，结合节拍判断是否保留重复。
- 画面可带另一个人物的肩、肩线上缘、手臂、手或身体局部。
- 前景必须建立关系、压力、亲密或冲突，不作随机装饰。
- 重要情绪节拍和动作要特别设计，可用运镜、调度、插入、停顿或多镜。
- 节奏快速简洁，关键节拍确有需要时同时安排信息镜头和情绪镜头。
- 直接呈现信息和情绪，避免意象、隐喻或象征切镜。
- 对白以固定镜头为主，非对白可用运镜或人物调度变化。
- 单人中景（头部到腰部）、单人中近景（头部到胸部）为主，特写支撑重点，全景每场约一两个。
- 变化景别、角度、机位和构图，避免重复覆盖。
- 镜头间通过动作因果、视线方向、空间关系和情绪递进衔接。
- 写法具体可执行。起幅技术信息放 `摄影机`，动作、表演、台词、镜头发展、落幅放 `分镜内容`。
- 使用直接控制画面的措辞，如 `画面主体只有……`、`只看到……`、`不拍完整人物`、`画面边缘……`、`过……肩拍……`、`手持微晃`、`固定镜头`。
- 最终镜头描述除非绝对必要，否则不用否定说明。直接设计画面，如 `Sophie向前走，镜头跟着Sophie向右横摇，Oliver退到Sophie身后`。
- 暴力或身体动作按需拆为意图、接触、身体反应、可见伤势/结果和情绪余波。
- 已在场人物即使不说话，也可安排反应镜头，只要能呈现压力、震惊、轻蔑或权力。
- 第一稿不能过疏，应接近真实制作拆镜的细度。
- 相邻镜头重复主体、景别、角度和节拍时，结合严格时长决定能否合并；长台词需要短镜承载时，安排有作用的反应与构图。
- 每个活动身体局部写明归属，如 `Sophie的右脚`、`Caroline的右脚`、`Alessia的双手`。
- 可见或活动的手、手臂、肩、腿、脚、身体侧面，必须写明所属人物及左右。不用 `一只手`、`另一只手`、`另一侧手`、`一侧`、`另一边`。
- 维持镜间位置、纵深、姿态、朝向、左右肢体使用、接触、道具、服装、伤势和情绪连续性，不逐行机械复述上一镜完整落幅。
- 运镜须符合所述机位和演员姿态的物理可能性。
- 轴线连续性必须保持。确定 180 度轴线一侧，整场固定肩位配对。用户双人样本中，拍 Owen 始终过 Nate 右肩，拍 Nate 始终过 Owen 左肩。没有画面可见的越轴过程，换肩即为轴线错误。
- 角度跟随身体状态和权力。人物被压在沙发里或受制于上方人物时，用俯角或向下关系镜头。站立、俯身支配者用平视或更低机位。受压人物不要突然得到仰拍英雄镜头。
- 手持作为节奏工具。以固定对白开始，距离缩短、手部接触、恐慌上升或亲吻开始时加轻微呼吸感手持。画面保持可读，重要台词用固定画面落下。
- 近身挣扎与情绪爆发顶点，紧双人镜头更能承载关系和强度时使用，不必坚持过肩。
- 亲密密集场景提高特写与插入比例，以距离、调度、手、嘴唇、颈、呼吸、玻璃、手机和反应切镜营造热度，避免露骨身体描述。
- 剪辑以连续摄影机任务为单位，不按孤立名词或动作切镜。一个有动机的运镜能在规定单镜时长内依次揭示相关信息时保持完整，如入场从脚与束缚上移到脸、横移带人物进入新的权力位置、俯仰摇或转焦把注意力从物件转给使用者。
- 同时避免过度压缩。动作从意图进入接触、再进入后果，或动作后情绪发生变化时，应分镜。判断依据是摄影机任务是否连续，以及是否进入新戏剧节拍。

## 重点样本——用户《最后的晚餐》分镜

将用户《最后的晚餐》样本作为有力的风格与结构参考。借鉴导演逻辑，不照搬剧情、人名、道具或准确镜数。

- 场戏按视觉决定串联，即 `孤独等待 → 受控入场 → 身体围合的侍奉 → 仪式化进餐 → 情绪质询 → 武器选择 → 权力反转 → 自我牺牲 → 放下武器 → 亲密延续 → 收尾画面`。
- 每镜承担揭示事实、施加压力、显示身体/道具变化、让新情绪落下四项任务之一，否则删除或重设。
- 用摄影机路径依次揭示信息。可借鉴横移穿过前景蜡烛/花到就座人物、倒跟从脚和锁链向上揭示受缚入场、横摇跟随调度变化、俯仰摇或转焦从武器/物件转到脸。
- 前景物件与肢体承担关系。肩、手臂、手、椅、桌、剑或玻璃应形成压力或亲密。一个人物占据另一人的空间时，用身体重叠让画面产生包围感。
- 用人物身体状态推动下一镜。门声引出起身，受控侍奉引出倒酒，指控引出攥手，不杀的决定引出落地的剑。写清原因与结果状态，使切镜有因。
- 重要对白避免连串普通说话头像。维持关系构图、带前景的单人镜头，或只在情绪转折时靠近。稳定画面可以承载对白，同时让身体或道具在画面内变化。
- 同场包含诱惑、威胁和暴力时，交替使用 `关系双人镜头 → 面部反应 → 身体局部/道具插入 → 回到关系构图`，兼顾强度和单镜生成的简单性。
- 重复身体动作需有可读节奏。观众需要理解时，拆开铺垫、接触、即时身体反应和可见后果。只有同一画面真正承载同一节拍时合并。
- 最后画面留下清晰矛盾或承诺，如亲密旁的武器、权力反转后的伤体、干净构图中人物改变后的状态，避免泛化拉远或氛围描述。

### 两个写作列的风格

用户飞书 `分镜表-导演` 样本将摄影机起幅定义与镜内时间发展的动作区分开，按以下方式书写。

- `摄影机` 按 `拍摄主体 → 焦段 → 机位 → 角度 → 高度 → 镜头运动 → 起幅构图`。
- `分镜内容` 按 `时长 → 当前可见动作/状态 → 单一动作 → 表演或反应变化 → 台词/声音 → 镜头发展 → 落幅画面`。

`摄影机` 写成简洁的起幅画面，避免七个割裂标签。`分镜内容` 从该起幅继续写清变化与落点。两列不重复完整起幅设置，不用一串氛围形容词代替可见动作。

## Seedance 与 AI 视频限制

- 非必要全景，一镜竖屏不放四五个人。
- 面对面一镜无法同时清晰展示双方表情。
- 不把不同信息点硬塞进同一全景。
- 视觉描述用可见主体与动作、视线方向或前景身体局部表达关系。声音部分明确写出画外说话人、原台词片段及跨镜续接。
- 每镜承载一两个动作或一个情绪点。
- 避免主体过多或视觉任务分散，以免 Seedance 误解。
- 复杂动作拆出身体局部或关系，如膝部被踢、手抓握、裙上血迹、手中瓶子、掐颈双手、脸失去焦点。
- 全身或双人动作可能混淆 AI 时，后接近镜或插入，澄清关键信息。
- 身体插入必须交代身体局部归属，避免 Seedance 多生成一人。
- 暧昧或亲密动作每镜保持简单，如一次触摸、一次姿态变化、一次道具揭示或一次反应，不一镜写多个亲密动作。
- 霸凌或公开羞辱动作每镜情绪清楚，如一次控制、一次打击、一个可见后果、一个施暴者反应或一次受害者崩溃。
- 奇幻或高概念场面中的超自然物件、翅膀、印记、发光眼睛或看似象征的插入，必须是剧本具体信息，不自创隐喻镜头。

## 如何应用参考样本

1. 只提取实用导演偏好。
2. 观察镜头节奏、过肩使用、切特写时机、运镜风格、反应密度、连续性逻辑和关键节拍强调方式。
3. 不照搬不适合当前剧本的故事内容、台词或视觉细节。
4. 适度应用，除非用户明确要求强模仿。

## 三个高冲击参考的共通规律

选用具体样本说明前，先应用此处规律。DATWD 霸凌片段与 Broken Wing 奇幻片段虽世界不同，导演逻辑相通。

- 核心为公开权力施加于脆弱身体。拍清谁掌权、受害者身体在哪、承受什么压力，以及谁旁观或获益。
- 镜头节奏在规模与身体之间切换，即 `全景/权力背景 → 受害者状态近镜 → 身体局部或道具插入 → 施暴者/权威反应 → 受害者余波`。
- 痛苦、惩罚、救援或重生按原因、接触或压力、可见后果、反应和情绪余震展开，不概述带过。
- 反复以受害者状态镜头为锚点，回到下跪、被按住、窒息、倒地、沾泥、受伤、微弱呼吸或刚转化的身体。
- 关键物件与身体印记传递剧情。血、裙、手机、瓶、吊坠、泥、翅膀、印记和眼睛，都写成有前后变化的具体可见状态。
- 反应镜头在增加压力时有用，如嘲笑、嫌恶、震惊、公众沉默、被保护的家人、权威裁决、救援者关注或人群恐惧。
- 公开曝光戏可用媒体见证镜头呈现社会后果，如狗仔长焦、取景器/监视器、闪光灯爆闪或受遮挡机位拍到关键公开行为。证明动作已被看见时，该镜头承担有效强调。只有制作速度或视频生成复杂度需要更精简版本时，才可省略。
- 奇观必须使利害关系更清楚。吊灯大厅、天空城、翅膀、火或人群镜头先说明权力关系，再回到脸、手、呼吸、伤口或物件。
- 收尾要有力且易读，如受害者伤势、控诉、倒地、物件揭示、救援者掌控局面、转化或复仇铺垫，留一个强画面。
- AI 生成每镜保持简单，即一个主体重点、一个动作或状态变化、一个清晰物件/身体细节。避免一镜解释整个权力结构。

## DATWD 演示校准

用户 DATWD 样本呈现以下偏好。

- 威胁、羞辱、暴力、伤害、复仇、倒地场面，镜数应多于概述式初稿。
- 从空间权力开始，交代谁控制身体、谁进入前景、谁高谁低。
- 过肩与局部身体建立关系，同时允许清晰面部镜头呈现 Alessia 的恐惧、疼痛、震惊、崩溃，以及 Sophie/Caroline 的轻蔑。
- 拆清主要动作，即 `Oliver靠近 → Sophie打断 → Alessia下跪 → Sophie踢击 → 出血 → Alessia察觉 → Alessia挣脱 → 掐颈升级 → 瓶子击中 → 倒地 → Caroline踢击`。
- 膝、手、肩、裙上血迹、瓶子、掐颈的手、踢击的脚，积极使用插入与局部构图。
- Caroline、Oliver、Lea、Joy 已在场，且反应能加强社会性羞辱或残酷时，可用反应切镜。
- 不把用户直接有力的节拍结构整理成更工整却更弱的版本。
- 以 `1G` 式横摇为正例，即 Sophie 上前，镜头跟随横摇，Oliver 退到她身后，Sophie 落在 Alessia 面前。
- `1L/1M` 主体、景别、情绪状态相同时，不拆成两镜。
- 拍裙上血迹的察觉过程时，机位须能合理看见 Alessia 低头看裙，再看脸。避免不可能的俯角转面部运镜。
- 近身掐颈与情绪爆发时，紧双人近镜可能优于过肩，因为身体贴近且情绪达到顶点。

## 《禁忌女医》演示 V1 校准

用户提到 `禁忌女医demo-V1`，或要求暧昧/亲密戏校准时使用。

- 参考视频约 84 秒有效画面，之后为黑尾，覆盖第二场玻璃房戏。
- 偏好高密度近距离覆盖，以中近景、特写、紧双人和插入为主，开场后很少使用全景/环境镜头。
- 场景反复使用近构图，包含红帘/玻璃背景、暖逆光、靠画面边缘的身体和浅景深。
- 首节拍从侧面/身体设置开始，迅速进入近距离双人压迫，不久留建立镜头。
- 对白与权力交锋台词交替使用近镜，单人之间穿插紧双人和身体重叠镜头，避免机械正反打。
- 亲密通过具体而克制的细节呈现，如手在颈/下巴、肩/肩带、唇、脸颊、颈、胸口高度构图、手机插入、玻璃房关系。不写露骨性动作措辞。
- 暧昧升级用较多微细节插入与反应相邻镜头，如抬下巴、唇接触、唇上血、肩颈处的手、手机震动、来电名、持手机的手。
- 亲密中段按 `特写 → 紧双人 → 身体局部插入 → 特写 → 紧双人` 组织，在单镜负担可控的前提下形成热度。
- 手机打断拆为手机插入、Kyle 察觉、手机在手、Aira 持机/反应、下方 Wayne、戴面具的 Wayne 特写、最终玻璃房关系构图。
- 收尾呈现关系画面，即 Aira 与 Kyle 在玻璃房内，Wayne 在下方，或通过反射/手机连接，让丑闻或揭示同时可读。
- 以该视频校准时，聚焦拆镜与分镜写法。用户要求忽略表情或视线分析时，提取摄影距离、主体、构图、运镜、身体/道具节拍，不写表情/视线拆解。

## DATWD 霸凌第一集 V1 校准

用户提到 `离婚日demo-ep1_V1`，或要求霸凌、公开羞辱、激怒观众、受害者崩溃场面的校准时使用。

- 参考视频约 61 秒，场景为高档订婚宴空间中的公开霸凌/羞辱。
- 主要目标为视觉冲击和情绪调动，让观众替受害者愤怒并期待反转。
- 覆盖顺序为 `公开场合建立 → 施暴者/权力人物入场 → 受害者被控制 → 命令/威胁 → 被迫身体姿态 → 接触/伤害 → 可见后果 → 残酷反应 → 受害者崩溃 → 对抗/复仇钩子`。
- 先让社会空间可读，用一两个较宽镜头交代高级场所、人群和控制者，再迅速进入近距离覆盖。
- 重视受害者被控制的镜头，如肩上的手、被抓住的手臂、身体被压下、膝盖/身体失控。写明手、脚、手臂所属人物。
- 强迫下跪或倒下时，拆清肩/手臂控制、下压力、身体下降、脸/身体反应。
- 打击暴力拆出意图、接触、身体反应和后果，关键后果不藏在全景。
- 伤势直接可见，如白裙血迹、手触污迹、受害者低头，再到脸部反应，不用隐喻切镜。
- 重视施暴者单人镜头。Sophie/Caroline 这类人物嘲笑、命令或享受羞辱时，可用干净单人或中近景。
- 旁观/人群反应在增加社会压力时使用，如震惊宾客、残酷笑容、僵住的家人或旁观的权力人物。
- 吊灯/金色奢华背景与羞辱形成对照。贴近受害者和伤势，周围以人群或施暴者暗示豪华场所。
- 受害者崩溃需多个近镜，分别承载察觉、难以置信、身体疼痛、哀求、愤怒、尖叫。
- 收尾情绪强烈，如受害者尖叫/伸手/控诉、可见伤势、施暴者支配或人群压力，推动观众期待反转。
- 避免把霸凌简化成普通打斗覆盖，需拍清公开贬损和可见后果。

## DATWD 霸凌第二集 V3 校准

用户提到 `离婚日demo-ep2-V3`，或要求更强的霸凌余波、复仇反击、情绪崩溃校准时使用。

- 参考视频约 51 秒，开场即在情绪顶点，且大部分时间让受害者身体处于低位，强度高于第一段霸凌样本。
- 已处危机时，不强加新的建立镜头。剧本如此开场时，直接进入受害者愤怒、掐颈/挣扎或控诉的紧镜。
- 覆盖顺序为 `受害者顶点控诉 → 近身挣扎 → 手/喉部插入 → 突然介入/打击 → 倒地 → 施暴者恢复 → 受害者贴地哀求 → 权力人物侮辱 → 反复踢击/伤害 → 人群或反派取乐 → 延长受害者贴地特写收尾`。
- 用地面建立视觉权力关系。受害者被击倒后，在侮辱、踢击和反应之间回到贴地面部特写，作为情绪锚点。
- 暴力打断拆出袭来物件或攻击肢体、接触、受害者脸/身体失控、倒下路径、撞地、余震。
- 反复踢击不写成一段泛化动作。交替使用命令/侮辱、脚或身体局部插入、受害者身体回缩，以及能加强羞辱的残酷反应。
- 大特写呈现伤害与无助，如脸颊贴地、乱发遮脸、皮肤血迹/伤口、手抓布料、眼神失焦、嘴几乎不动。
- 反派和旁观反应在此风格中有作用。用冷笑、大笑、嫌恶、保护家人的姿态，或受害者被忽视时旁人受到安慰，使残酷具有社会性。
- 施暴者台词可落在近距离反派单人镜头，身体伤害另切插入或受害者身体反应，便于 Seedance 分清说话与打击。
- 收尾比通常更久停留受害者伤势，如贴地面部特写、可见伤口、弱呼吸、失焦眼睛或微动嘴唇，让观众产生愤怒。
- 余波保持身体质感，写出体重、接地、呼吸、撞击声、拖拽布料、失控乱发、微小失去意识细节，避免过分整齐的编排感。

## Broken Wing V4 May30 校准

用户提到 `broken wing_V4_May30`，或要求奇幻惩罚、堕天使/有翼救援者、公开审判、放逐、超自然身份揭示、重生式校准时使用。

- 参考视频约 158 秒，采用高概念奇幻惩罚与重生结构。
- 覆盖顺序为 `天界/世界建立 → 公开人群压力 → 受害者身体印记/背部揭示 → 权威裁决 → 关键护符/身份道具 → 跌入泥中 → 公开践踏/威胁 → 有翼救援者到来 → 护符找回/揭示 → 夜间余波 → 安静触碰/复苏 → 眼睛转化收尾`。
- 奇观用于传递剧情。天空城、翅膀、发光护符、身体裂纹、眼睛变化和火，在此都是具体世界/剧情元素。
- 世界规模本身构成钩子时，开场可比通常多留全景，但尽快从史诗规模进入受害者身体状态和公开裁决。
- 公开审判需拍清等级，包括人群背影、泥中低处的脚、权威近距离单人镜头、受制或暴露的受害者、带印记的背或护符。
- 关键道具形成视觉链，即 `戴在身上 → 被移除或受威胁 → 掉入泥中 → 救援者注意到 → 拾起 → 查看 → 归还或使用`。
- 身体印记和伤口写成状态信息，如背部裂纹、沾泥双手、脸上血、脸颊贴地、无力伸手，避免抽象痛苦措辞。
- 奇幻救援或反转拆为远处剪影/到来、人群或受害者反应、翅膀/身体细节、救援者落地或介入、物件互动、近距离情绪交流。
- 每次史诗画面后，回到受害者脸、手、呼吸或姿态，保持人物利害关系。
- 夜间余波更安静亲密，使用火光、俯卧身体、救援者跪下、手靠近护符、近距离面部，再到转化细节。
- 剧本铺垫成立时，可用超自然身份画面收尾，如发光眼睛、变化的脸、护符光、转化后直视前方的受害者，形成重生或复仇铺垫。

## 质量检查

交付前检查以下问题。

- 每镜是否呈现人物关系？
- 关键节拍是否得到超出普通单人镜头的强调？
- 单人对白的过肩、斜侧净镜头、高平低角度是否符合该节拍？同角度、同景别累计第 4 次起是否复核构图？
- 每个 `摄影机` 单元格是否按主体、焦段、机位、角度、高度、运镜、起幅构图完整书写？
- 每个 `分镜内容` 是否以时长开头，并写清动作、表演、有则保留的台词、镜头发展和落幅？
- 两列是否避免不必要的重复？
- 是否保留原剧本？
- 每镜是否简单到足以让 Seedance 理解？
- 每镜是否仅承载一两个动作或一个情绪点？
- 分镜细度是否足以执行？
- 镜间身体动作的因果是否可见？
- 镜号是否跳过 `I` 和 `O`？
- 是否统一为集数-场次加字母镜号，并按单集处理跨集连续戏？
- 是否先确定整集重点，再设计关键节拍？大段对话是否落实说话人之外的反应镜头？
- 是否按主规则逐集核验 95% 短镜、4 秒上限，以及原台词跨镜完整性？
- 身体局部动作是否明确归属人物？
- 角度与运镜在物理上是否兼容？
- 最终内容是否去掉不必要的否定拍摄说明？
- 霸凌戏是否拍清公开羞辱？
- 霸凌戏的接触与后果是否拆得清楚可读？
- 高强度霸凌余波是否以贴地受害者特写作为情绪锚点？
- 反复暴力中的命令、接触、身体反应、可见伤害，是否区分到足以供 AI 生成？
- 奇幻/高概念场面的超自然细节是否作为具体剧情信息处理？
- 史诗奇观的全景或超自然镜头后，是否回到人物处境？
