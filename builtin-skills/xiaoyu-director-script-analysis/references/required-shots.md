# 必需镜头的判断规则

先读一集，圈出观众必须看懂的事实、最该停留的情绪、最值得放大的动作。问一句：删掉这个视角，观众会错过什么？答案可能是证据、人物的决定、公开羞辱的分量，或近在咫尺却错过的遗憾。普通交代戏有合适的观看方向就够了。

| 何时判为必需 | 写给分镜的要求 |
|---|---|
| 第一集开头 | 必须给出一个能抓住观众的具体镜头设计。写第一眼看见什么，跟谁或什么移动，落在哪个有剧情意义的画面。安静的戏也能靠反射、遮挡揭示或视角转换抓人。只分析中段时不补写片外的开场。 |
| 前十集 | 逐集找最有吸引力的节拍，优先保障人物首次出场、误会成立、第一次反击、高潮和卡点的覆盖。第一集开场单独设计；其余各集从本集真正重要的地方下手。 |
| 关键物件或动作承载因果 | 给物件或动作特写，写明必须读清的字、归属、动作接点或状态变化。如黑卡被夺，要看清由谁手里到了谁手里、卡上是谁的名字，以及谁认出了名字。多个物件提供不同线索时分别交代。 |
| 情绪或权力转向 | 明确给谁脸部近景，以及压在哪句话、哪声响、哪个发现之后。优先给受到刺激、作出决定或试图掩饰的人。听见死者留下的表要被毁，求饶者第一次失去镇定，这一拍比多拍一次说话人重要。 |
| 爽点、虐点、错过或重逢 | 把最值得延长的瞬间拆成不同观看位置，每个角度各交代一件事：两人的关系位置、动作触点、当事人主观感受或旁人目击。需要慢动作时点出从哪里开始、到哪里恢复常速。多角度对齐动作方向、视线和物件状态。 |
| 群戏里的重要时刻 | 点名主角、关键配角，再写一组在场群演的反应。交代各自知道什么、看向哪里、反应怎样不同。可以一次横摇或一个群体镜头带出多人；决定、隐瞒、识破等细微变化要有可读的单人反应。只用原场已有的人。 |
| 误导、悬念、跨场衔接 | 锁住谁先看见、谁只听见；写出本场能露到哪里、集尾停在哪一帧或哪张脸。需要监控回放、手机偷拍、反射画面、跨集同一动作时，指定须保留的视角与接点。 |
| 运动本身承担揭示 | 只有指定的移动关系决定看懂这拍时才锁进必需栏。写起幅、触发、运动和落幅：从谁身后跟出，被谁挡住，何时露出谁。其余推拉、横移或转焦的机会交给“视觉重点”提示。 |

**怎么落到表里**

- 视觉重点写观看意图及可加密的地方，例如“这杯酒把私下的敌意变成公开羞辱，可以在酒泼出到全场噤声之间拉长”。必需镜头用明确指令，每个观看要求单独一行，写具体主体、动作时点、景别或角度、必须看见的结果。理由用于判断，有必要才写进格内。
- 以泼红酒为例：① 侧面双人中景，交代谁先扬杯、谁正面对她。② 自杯口翻转到酒点打上女主脸颊用慢动作特写。③ 恢复常速，正面近景留住女主压下羞耻、重新抬眼的变化。④ 若现场有宾客，给关键配角放下酒杯的反应，再从女主身后看围观的人一齐转过来。具体反应以本剧人物为准。
- 以擦肩错过为例：① 侧面关系镜头，先让观众看清两人会在同一点交会。② 从一人肩后看另一人掠过，短暂升格落在几乎回头的瞬间。③ 反向近景接住另一人的迟疑；恢复常速时，两人已向相反方向走开。若原稿规定某人始终未察觉，镜头只拍观众所见，保留人物的未知。
- 每场写完回查：关键动作的起因和结果能否剪接？受影响的人有没有可读的反应？群众反应有没有泄露他们还不知道的事？单镜能同时完成的任务可合并；明确指定的不同角度、独立特写、慢动作范围和揭晓顺序逐项保留。连接场没有额外硬要求时此栏留空。
