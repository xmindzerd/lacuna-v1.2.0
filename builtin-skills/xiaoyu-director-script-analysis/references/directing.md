# 从几次读本里留下的导演判断

## 「总结Director List规则」的十条共性

《Revenge League》重视危机、爽点和主线进度；《LTD》把矛盾、人物关系和配角反应写进每场；《Our Family》重视表演节拍、遮挡、转场和揭晓；《Lady Diamond》强调人物造型、关键道具状态及复杂画面的执行条件。以下十条是原对话总结的规则，以及它们在 AI 短剧逐场表里的用法。

| 原规则 | 填表时怎么用 |
|---|---|
| 1. 以原场号定位 | 原表允许连续场合写。本 skill 按原场号逐行，连场用交接的动作或声音串起来；同地、同日也保留各场。 |
| 2. 先判断这场为什么存在 | 找出核心矛盾，以及它让主线、关系、认知或地位产生的变化。标对本集的开头、高潮、结尾和钩子；爽点要写出前面压住了什么、现在谁扳回一局。 |
| 3. 主动识别剧本问题 | 留意重复、主线被支线挤走、主角高光落在旁人身上、人物动机或当地职业与阶层逻辑站不住。先看能否靠表演、取景和信息顺序讲清；确需改剧本时在交付消息点出对应场号。涉及删戏、重排或改台词，由导演另行决定。 |
| 4. 视觉笔记能指导出画面 | 指出谁先被遮住、何时露脸、用谁的视角、哪件证据必须读清、转场怎样相接。只有当空间关系或信息揭示依赖某种景别、运动、补充画面时才点明。 |
| 5. 表演按节拍拆 | 用“受到什么刺激→先掩饰或抵抗→露出怎样的真实反应”。对照前后场和对手的地位变化。群戏找出谁先察觉、谁跟着变脸、谁的沉默最有分量。 |
| 6. 服化道服务人物和剧情 | 用角色身份、阶层、年代、阵营或关系解释必要的服装区别。道具写清它承担的戏，以及影响辨认的特征。只有确实需要时，才写已定造型参考、标识、尺寸或完整／破损版本。 |
| 7. 检查连续性 | 查同一故事时间里衣服、伤妆、湿痕、手中物和人物站位。手机视频、新闻、照片、监控若要重放，标清源场次、当时造型、视角和可见范围，给制作准备匹配画面。 |
| 8. 考虑实现难度 | 多人反应、空间转换或道具变形容易让 AI 画面接不上时，在“特殊要求说明”写出要守住的视觉结果。可用单人反应、独立屏幕素材或变化后的道具状态讲清同一拍，保留原剧情因果。 |
| 9. 普通场允许留白 | 只写对这场有用的造型、氛围、关键道具和特殊要求。团队栏始终留空。 |
| 10. 颜色按项目解释 | 原表颜色可能代表剧本日、段落或工作优先级，含义随项目而变。项目给了图例才按其解读；交付时节拍和关键信息用文字表达。 |

**单集落进逐场表的例子。** 《海外版打小三》第 10 集，10-1 的【开头】是儿子拧不开门，又敲一次；10-2 的【高潮】是母亲听到儿子就在外面，却没能让他发现自己。【结尾】落在门开、儿子问“你们在干什么”，【钩子】是观众还没看到他的视野，不知道他发现的是母亲还是满屋狼藉。下一集才揭示的答案要留住。

## 逐场判断示例

**一场先找决定性的变化。** 《Craving Love》车内戏的开头和结尾各问一次“谁能决定车里发生什么？”特蕾莎从忍着开车到突然急刹，才有下一场赶人下车。拍摄重点可以落在后视镜里她的目光、手指攥紧方向盘、急刹之间的先后。情绪重点解释她是在哪一下再也忍不住。同样是赶人，换成她一开始就决定停车，就得换一套拍法。

**把观众看懂的信息和人物接到的刺激分开写。** 《关键试镜》要求关键节拍同时有信息和情绪。《shadow star demo》里，撕协议改变两个人的关系，记者看到并拍下才让拒绝成为公开事件。判断方法是问“谁刚刚看见了什么，局面因此怎么变？”转场如果只靠一个目击就成立，这场就写那个目击，不硬凑高潮。重点戏留出人物消化消息的时间。

**空间得让戏真的能发生。** 《最后的晚餐demo》里，两人已离开餐桌到了墙边，远处烛火无法承担脸上的主光，这时要顺着窗的位置找光。《Craving Love》别墅戏则先确认二楼过道、玻璃厅和楼下沙发的视线。先判断谁需要看见谁、谁必须看不见，再写空间和氛围。发生在同一房间的几场戏，可以用敲门声、门外脚步、室内突然停下的说话声区分紧张感。

**衣服和道具要对得上演员的动作。** 衣领是否允许关键物件入画？物件先前在哪个人手里？摔碎以后，下一场能看见哪些残片？只列会影响叙事或需要接戏的东西。原稿明确的标识、颜色、数字和破损时机要准确。连续多场同一套衣服，只在首次建立、状态改变或易接错时提示。

**让剧本决定节奏和风格。** 人物戒备和害怕可以同时存在，给演员一个可演的转换，如“她先看屏幕确认姓名，才抬眼质问对方”。紧张也可能来自体面场合里所有人等一句回答。以往项目提出的手持比例、镜头秒数、肤色、配乐或造型都属于该项目。换剧本后重新从人物、剧种和场面找依据。
