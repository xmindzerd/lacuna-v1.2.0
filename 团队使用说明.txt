Lacuna V1.2.0 · Windows 10/11 x64 团队版

从 V1.1.6 或 V1.1.55 原地升级
1. 从团队共享文件夹下载完整 ZIP，解压到一个新文件夹。保留原安装目录及项目资料，接回原来存放资料的移动磁盘。
2. 保存进度，退出 Lacuna（含系统托盘）。双击新解压目录里的「升级一键成片.exe」。
3. 核对原安装目录。V1.1.6 的主程序是 Lacuna.exe，V1.1.55 是 Lacuna-V1.1.55.exe。升级工具校验文件后覆盖安装并更新桌面快捷方式。
4. 双击桌面「一键成片」，从最近项目继续。首次启动优先继承 V1.1.6 窗口设置，其次继承 V1.1.55。若提示文件占用，请退出程序后重试；若提示目标文件与发行包不符，请先备份该文件并与负责人核对。

首次使用与连接
完整解压到可长期使用的可写目录，双击 Lacuna.exe。需要 .NET Framework 4.8，部分即梦工具需要 Node.js 18 或以上。可运行升级工具并选择当前解压目录来创建桌面快捷方式。
在「设置」选择项目保存位置。在 Codex 连接设置中可使用自己的 Codex 账号，也可切换到 OpenAI Responses API，填写 API 地址、模型 ID 并保存项目 Key。
要仅让资产图片走 API，在设置保存可用的 API 地址、模型 ID 和 Key；全局选择 Codex 账号，创建项目时把「资产出图渠道」设为「OpenAI Responses API 生图」。其余分析和提示词步骤沿用账号连接。

一键成片
工作台点「一键成片」，导入剧本，选择对白语言、资产出图渠道和审核方式。新项目固定竖屏 9:16，资产图使用横向 4:3。五项内置 Skill 随包提供，负责导演剧本分析、视觉设定、资产出图规则、竖屏分镜与最终提示词。需要团队自有写法时，可选择自定义最终提示词 Skill。
在项目全览查看六阶段进度。开启资产人工审核时，在资产页确认图册后点击「一键确认全部资产并继续制作 ›」。最终提示词审核后，可进入视频生成，选择即梦模型、分辨率和片段，分批核对报价再提交。即梦使用成员自己的授权。中断后请先用原任务号查询并取回已提交的片段。

问题反馈
在工作台或设置点「问题反馈」→「新建反馈」。填写发生时间、环节、操作步骤、预期和实际结果，可选择或粘贴截图。「匹配并预览日志」会列出有关摘录；检查截图与日志，移除无关证据后点「开始分析」，使用当前账号或 API 连接生成诊断。
离线时可直接「导出报告」。从记录旁的「反馈报告」打开文件夹，将 Lacuna-反馈-….zip 交给负责人。补充证据后可重新分析或导出。
